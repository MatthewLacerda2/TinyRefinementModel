## Notes

- **Why this is a champion but not a result.** #16's proof gate did **not** pass: the
  refiner beat the `reasoner` control by 0.0235 nats at the matched step, which sits
  inside the 0.03-nat seed noise floor (#17). It is a tie. The card exists so the
  weights can be warm-started from, and so the comparison can be re-run — not to claim
  depth recurrence won.
- **The continuation ran past the LR schedule.** `DECAY_STEPS=1526` ended at ~step 1540;
  the 6.6h continuation (`run_20260720_235421`, steps 1540 → 2240) therefore trained at
  the LR floor. Val CE still fell 4.8947 → 4.7092, so the model was nowhere near
  saturated — consistent with "undertrained, not incapable."
- **`best/` was stale — do not trust it.** Across all three #16 runs the best-val
  checkpoint tracker stopped updating (`best/` topped out at step 1540 for the
  continuation while val CE improved monotonically to step 2240). The kept checkpoint is
  the *latest rolling* one, which is genuinely the best. Worth an issue.
- **`git_dirty: true`** on both arms. Strict recipe reproducibility is therefore not
  guaranteed from the SHA alone — the config snapshot above is the authoritative record
  of what ran.
